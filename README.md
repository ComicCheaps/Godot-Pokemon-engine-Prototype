# Pokémon DS-Style Engine

> An unfinished, open-source Pokémon-inspired game engine focused on recreating the feel and technical foundation of the Nintendo DS-era Pokémon games.

## About

This project is an experimental **DS-style Pokémon engine** built from the ground up.

The original goal was to create a flexible foundation for building a Pokémon-style game, including the core gameplay systems, graphics, and development tools needed to create a complete game.

The project has reached the point where several major systems are functional, but development has been temporarily put on hold due to the overall scope of the project.

Rather than letting the project sit unused, the repository is being left **open for anyone interested in continuing development, experimenting with the engine, or adding their own systems.**

## Current Features

### ⚔️ Battle System

The engine currently has a functional Pokémon-style battle system.

* Turn-based battles
* Battle flow
* Pokémon data
* Moves and battle mechanics
* Battle UI
* Damage and combat logic

> The battle system is one of the most developed parts of the project.

### 🎨 Advanced Graphics

The engine includes a number of graphical systems intended to recreate the visual style and presentation of DS-era Pokémon games.

The graphics system is still experimental and may change significantly if development resumes.

### 🛠️ Primitive Editor

A basic editor is included to make creating and modifying game content easier.

It is currently **primitive and unfinished**, but provides a foundation that can be expanded into a much more capable development tool.

### 🧩 Expandable Architecture

The project is intended to be expanded by other developers.

Systems can be modified, replaced, or built upon without requiring the entire project to be rewritten.

## 🚧 Current State

**Development Status: On Hold**

The project is **not a finished game or complete engine**.

Currently:

| System          | Status                     |
| --------------- | -------------------------- |
| Battle System   | 🟢 Working                 |
| Graphics        | 🟢 Advanced / Experimental |
| Editor          | 🟡 Primitive               |
| Pokémon Sprites | 🔴 Not Included            |
| Full Game       | 🔴 Not Complete            |
| Development     | 🟠 On Hold                 |

The project was temporarily paused because completing the full engine and game would require substantially more development time than was available before **Ship-a-thon**.

There is no guarantee that development will resume.
